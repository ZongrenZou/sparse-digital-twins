This repository contains source code for the paper: Sparse Stochastic Digital Twins Can Outperform Exact Ones. It requires the following dependencies to be installed:

- Python 3.10.0
- SciPy 1.15.3
- NumPy 2.2.6
- Matplotlib 3.10.3
- Jax 0.6.2
- Flax 0.10.6
- Optax 0.2.5
- Diffrax 0.7.0
- PyTorch `2.8.0.dev20250506+cu128`
- Gymnasium 1.2.3
- Stable-Baselines3 2.7.1
